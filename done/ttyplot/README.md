###### Подсказки
- Флюс на чувствительном элементе датчика?
- Повторная калибровка после впаивания — в инструкции явно написано, что этого делать не нужно
- Параллельный замер другим датчиком температуры
- 100500 раз проверить код — особенно переходы между системами счисления и сборки многобайтовых чисел
- Проверить, не кидает ли протокол I2C сигнал NACK
- Дать системе время закончить измерения после запроса, потом считывать
- Закинуть код в LLM и спросить, в чём проблема
- Искать на графике показаний асимптотические кривые нагревания — они намекают на нагрев от платы
- Значения MSBFIRST или LSBFIRST при настройке I2C
- После отправки сообщения чтения следующее сообщение отправляется NOP = 0x0000 при котором возвращаеться уже измереные данные
- Проверить, нет ли нагрева от соседних компонентов


###### Эксперименты
- [-] Отключить измерение влажности
- [+] Уменьшить число замеров, по которым идёт усреднение температуры (0x3f — это и температура, и влажность по максимуму)
- [+] Поставить в CTRL_REG1 BDU-бит в 1 — это гарантирует, что старший и младший регистры показывают значения из одного и того же замера
- [+] Проверять STATUS_REG перед считыванием (показывает, готовы ли данные)
- [+] Выводить TEMP_OUT_L и TEMP_OUT_H отдельно
- [+] Выводить расчитанную температуру

#### Кстати про асимпторические кривые
- [ttyplot](https://github.com/tenox7/ttyplot) нарисует нам графики прямо в терминале
- `stty` настроит терминал так, чтобы его было удобно читать
- `cat` считает данные прямо с порта будто из файла (без эмулятора терминала)
- `awk` (точнее, gawk) преобразует данные в формат для рисования

##### Случайные данные
```bash
while true; do
  echo $((RANDOM % 100))
  sleep 0.1
done | ttyplot -t "Random" -u "value"
```

##### Пример для микрофона
> [!CAUTION]
> Да, он тоже не работает. \
> Повезло мне с платой

Выясним порт платы, чтобы читать с него напрямую:
```bash
ls /dev/cu.usbmodem*
NANO_PORT=/dev/cu.usbmodem•••
echo $NANO_PORT
```

> [!TIP]
> Зачем нам переменная среды? \
> А просто мы несколько раз будем использовать этот адрес

Настроим порт:
```bash
stty -f "$NANO_PORT" 115200 raw -echo
```

Напишем pipeline:
```bash
cat "$NANO_PORT" |
  gawk 'match($0, /L p2p=([0-9]+)/, m) {
    print m[1]
    fflush()
  }' |
  ttyplot -t "Microphone P2P: " -u "PCM"
```


##### Закрепим, хм, успех — пример для датчика температуры
```bash
cat "$NANO_PORT" \
  | awk '/^Temperature = / { print $3; fflush() }' \
  | LC_NUMERIC=C ttyplot -t "HTS221 temperature" -u "degC" -M 0 -m 40
```
